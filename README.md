# JuneBug

JuneBug is my very first class library for Monogame. I plan to model it to support a variety of features and to use this to create my own games.

I want JuneBug to support the following features:
    
    - A Hierarchy-based system.
    - Draw Handling
    - Input Management
    - 2D Sprite Support, including Sprite Sheets and Animation
    - User Interfaces
    - Collision System
    - Basic 3D Rendering Capabilities
    - XML and JSON Parsing
    - AOT compatibility
